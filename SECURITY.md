# Política de Segurança — Mundo Kids

Este repositório contém somente código público do frontend. Chaves administrativas, service role e outros segredos de servidor não devem ser armazenados aqui.

## Reportar uma vulnerabilidade

Use o canal privado de Security Advisory do GitHub:
https://github.com/lucasjanoca/Mundo-Kids/security/advisories/new

Evite publicar detalhes exploráveis em Issues públicas antes da correção.
