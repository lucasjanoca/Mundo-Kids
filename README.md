# Mundo Kids Brinquedos — site 2.0

Site responsivo e pronto para GitHub Pages.

## Recursos
- visual inspirado nas cores da marca;
- navegação por idade e categoria;
- vitrine de produtos;
- assistente para encontrar presente;
- integração com WhatsApp;
- localização da loja com mapa;
- layout responsivo para celular e computador;
- SEO básico e página 404.

## Observação
Os produtos exibidos são demonstrativos e podem ser substituídos pelos produtos reais da loja.

## Publicação
GitHub Pages: branch `main`, pasta `/root`.
